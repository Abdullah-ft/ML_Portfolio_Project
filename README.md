## 🚀 Project Overview

This project delivers two real-world machine learning solutions built to support data-driven decision-making in digital commerce and marketing:

1. **Classification Task**: Predicting whether an e-commerce order is likely to be returned (`1 = returned`, `0 = kept`) before shipping to reduce logistics and restocking costs.
2. **Regression Task**: Forecasting the 14-day trackable revenue (`USD`) generated by an influencer marketing campaign based on creator metrics, engagement, and promotional strategy.

Both models are encapsulated into production-ready `scikit-learn` pipelines (preprocessing + estimator) and deployed as interactive web interfaces using **Streamlit** and **Gradio**.

## 💼 Business Problems & Objectives

### 1. E-Commerce Return Risk (Classification)
* **The Problem**: High customer return rates erode e-commerce profit margins due to double shipping costs, warehouse handling, and item depreciation.
* **Target Variable**: `return_risk_label` (Binary: `1 = Returned`, `0 = Kept`).
* **Selected Predictive Features**:
  * `cart_value_usd`: Total checkout cart order value in USD.
  * `past_return_rate`: Historical return proportion for the customer (0.0 to 1.0).
  * `delivery_days_taken`: Estimated delivery duration in days.
  * `discount_pct_applied`: Promotional markdown percentage (0% to 50%).
  * `size_bracketing_flag`: `1` if the buyer purchased multiple sizes of the same item.
  * `product_category`: Item type (`Casual-Tops`, `Footwear`, `Accessories`, `Formal-Eveningwear`).
  * `fit_review_sentiment`: Buyer consensus (`True-to-Size`, `Runs-Slightly-Small`, `Inconsistent-Sizing`).
* **Business Value**: Enables proactive interventions such as dynamic sizing warnings, personalized exchange incentives, and return risk alerts at checkout.

### 2. Influencer Campaign Revenue (Regression)
* **The Problem**: Marketing teams struggle to forecast sales yield from creator partnerships and often overspend on paid amplification for low-yield campaigns.
* **Target Variable**: `campaign_revenue_usd` (Continuous trackable sales in USD within 14 days).
* **Selected Predictive Features**:
  * `creator_followers_k`: Creator audience size (in thousands).
  * `engagement_rate_pct`: Percentage of audience interacting with content.
  * `paid_boost_spend_usd`: Brand advertising budget allocated to amplify post.
  * `avg_watch_time_sec`: Average viewer retention before scrolling.
  * `promo_discount_pct`: Special discount offered via creator code (0% to 25%).
  * `content_format`: Deliverable medium (`Short-Video-Reel`, `Static-Carousel`, `YouTube-Deep-Dive`).
  * `audience_intent_tier`: Follower buying readiness (`Broad-Entertainment`, `Lifestyle-Warm`, `High-Intent-Niche`).
* **Business Value**: Allows marketing managers to optimize budget allocation, project campaign ROI before signing creator contracts, and balance organic vs. paid boost spend.

## 📊 Model Training & Methodology

### 1. Feature Preprocessing Pipeline
To prevent data leakage, all transformations are encapsulated in a `scikit-learn` `Pipeline`:
* **Numeric Features**: Imputed and standardized using `StandardScaler`.
* **Binary Features**: Passed through directly without distortion.
* **Categorical Features**: Encoded using `OneHotEncoder(handle_unknown="ignore")`.

### 2. Model Selection & Results

#### Classification (E-Commerce Returns)
* **Candidate Models**: Baseline Dummy, Logistic Regression, Random Forest Classifier, Gradient Boosting Classifier.
* **Tuning**: 5-Fold Stratified Cross-Validation optimizing for **F1-Score**.
* **Champion Model**: **Logistic Regression**
  * Selected for its high F1 performance, calibrated probabilities, and full explainability for business stakeholders.

#### Regression (Campaign Revenue)
* **Candidate Models**: Baseline Dummy, Ridge Regression, Random Forest Regressor, Gradient Boosting Regressor.
* **Tuning**: 5-Fold Cross-Validation optimizing for **Mean Absolute Error (MAE)**.
* **Champion Model**: **Gradient Boosting Regressor**
  * Outperformed linear models by capturing non-linear interactions between paid boost spend and creator engagement.
  * **Test MAE**: `≈ ±$530` on unseen campaign data.

To re-run the full training pipeline and update the saved models:
```powershell
python train_models.py
```

## 💡 Key Insights & Business Implications

1. **Size Bracketing is the Strongest Return Predictor**:
   Customers purchasing multiple sizes of the same item return with significantly higher probability. Recommending verified size guides before cart checkout can drastically cut returns.
2. **Paid Boost Amplifies High Engagement**:
   Ad spend allocated to content with high watch time and strong initial engagement yields exponentially higher 14-day revenue compared to broad, cold audience boosts.
3. **Delivery Delay Correlation**:
   Orders with longer delivery elapsed times exhibit elevated return rates, suggesting prompt logistics directly protects retained revenue.
